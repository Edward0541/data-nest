# Data Nest Premium Website

A full-stack React + Vite + Express starter for Data Nest.

## Structure

- `client/` → React frontend
- `server/` → Express backend

## Setup

### Frontend
```bash
cd client
npm install
npm run dev
```

### Backend
```bash
cd server
npm install
npm run dev
```

## Important
1. The logo file is already included at:
   `client/src/assets/data-nest-logo.png`
2. Update `client/.env` with your real Google Form link.
3. Update `server/.env` with your Gmail app password.
4. Deploy frontend on Vercel and backend on Render or Railway.
