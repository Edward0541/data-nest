# Data Nest Education Platform

A full-stack web platform for **Data Nest**, an education initiative that helps young learners develop practical skills in coding, artificial intelligence and robotics.

## Purpose

The platform introduces students to technology through structured learning content, guided projects and hands-on exploration. It supports Data Nest's goal of making STEM education engaging, accessible and practical.

## Technology Stack

- **Frontend:** React and Vite
- **Backend:** Node.js and Express
- **Deployment targets:** Vercel for the frontend and Render or Railway for the backend

## Repository Structure

```text
data-nest/
├── client/   # React frontend
├── server/   # Express backend
└── README.md
```

## Local Setup

### Frontend

```bash
cd client
npm install
npm run dev
```

### Backend

```bash
cd server
npm install
npm run dev
```

## Configuration

Create local environment files from the required variable names used by the application.

- Store the public form URL in the frontend environment configuration
- Store email-service credentials only in the backend environment configuration
- Never commit passwords, API keys or production secrets to GitHub

The Data Nest logo is located at `client/src/assets/data-nest-logo.png`.

## Product Direction

- Age-appropriate coding, AI and robotics lessons
- Interactive quizzes and learning activities
- Guided Arduino and robotics projects
- Progress-focused student experiences
- Resources for educators and parents
